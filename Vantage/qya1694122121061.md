Projects is a collaborative workspace within Teradata AI Studio used to organize, manage, and automate the end-to-end lifecycle of machine learning and artificial intelligence models.

Each Project consists of models, datasets, and other resources you use to train, evaluate and deploy a model in your environment.

-   To create a project and dataset connection, see [Create projects](vtz1725408102228.md) and [Dataset connections](wkm1725389190945.md).


-   To check the connectivity errors for a project, select ![Kebab menu.](Images/kbt1547502809538.png) > **View Git details**.


-   To archive a project, select ![Kebab menu.](Images/kbt1547502809538.png) > **Archive**.
