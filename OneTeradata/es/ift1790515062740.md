Revise la información del modelo y abra las tareas disponibles. El contenido del cuadro de mando depende de su rol y de la oferta de Teradata.

## Cuadro de mando para administradores


Revise la información sobre el modelo, el acceso y el despliegue, e inicie las tareas administrativas comunes. Con Teradata Factory, el cuadro de mando también incluye información del Registro de modelos.

**AI Gateway**

La tabla **Modelos incorporados recientemente** muestra los endpoints de los modelos agregados recientemente. Utilice la información disponible sobre los modelos para compararlos por tipo, proveedor, versión, longitud del contexto y límite de velocidad.

-   Seleccione **Ver todo** para abrir la lista de modelos en **AI Model Gateway**. Consulte [Explorar modelos](eoz1778496909062.md).


-   Si tiene acceso administrativo, seleccione **Endpoint del modelo** para agregar un modelo. Consulte [Agregar un modelo](fdy1778502087907.md).


**Registro de modelo**

**Nota:** el Registro de modelos solo está disponible con Teradata Factory y requiere privilegios de administrador.

Revise la cantidad de modelos registrados y desplegados en el Registro de modelos.

-   Seleccione un modelo registrado recientemente para revisar su estatus y detalles.


-   Si tiene acceso administrativo, seleccione **Importar modelo** para importar un modelo admitido. Consulte [Importar modelo](ecc1790524485875.md).


## Cuadro de mando para usuarios de datos


Utilice una clave API virtual para ver los modelos que se le han asignado y explorar otros modelos disponibles a través de AI Model Gateway. Si no dispone de una clave API virtual, póngase en contacto con su administrador del Centro de modelos de IA.

**Ver los modelos asignados**

1.  Introduzca la clave API virtual en **Introducir clave**.


1.  Seleccione **Enviar**.


El cuadro de mando muestra los modelos asignados a la clave API virtual. Los modelos asignados también aparecen en la pestaña **AI Model Gateway**. Consulte [Explorar modelos](eoz1778496909062.md).

Para usar una clave virtual diferente, borre la clave existente e introduzca la nueva.

**Comparar la capacidad del modelo**

Cada ficha de modelo incluye información sobre los tokens para ayudarle a determinar si el modelo cumple con sus requisitos de entrada y respuesta.

-   **Tokens de entrada** indica la cantidad de texto que puede enviar en una sola solicitud. Para historiales de conversación o documentos más extensos, elija un modelo con un límite de entrada más alto.


-   **Tokens de salida** indica la cantidad de texto que el modelo puede generar en una sola respuesta. Elija un modelo con un límite de salida más alto cuando necesite respuestas más largas.


El cuadro de mando muestra los modelos en una lista de forma predeterminada. Utilice el control de vista de tarjeta para cambiar a la vista de tarjeta.
