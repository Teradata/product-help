Configure el número de réplicas del modelo y los recursos asignados a cada réplica.

Revise la familia del modelo, el nombre, el tipo y el tamaño del modelo antes de configurar el despliegue.

**Réplicas**

En **Réplicas**, seleccione el número de réplicas del modelo que desea desplegar.

La configuración de recursos se aplica a cada réplica.

**Seleccionar un grupo de nodos**

En **Grupo de nodos**, seleccione un grupo de nodos que cumpla con los requisitos de carga de trabajo y modelo.

Revise los **Detalles del grupo**, que incluyen:

-   Recursos computacionales disponibles


-   Número de nodos


-   Recursos por nodo


-   Disponibilidad actual del nodo


Los límites de recursos mostrados dependen del grupo de nodos seleccionado.

**Configurar recursos**

Elija cómo asignar recursos a cada réplica:

-   **Estándar:** utiliza la asignación de recursos predeterminada que se muestra.


-   **Personalizado:** permite ajustar la asignación de recursos para cada réplica.


Para un modelo preempaquetado, utilice los valores de memoria, CPU y GPU documentados para la fuente y el paquete de modelo seleccionados.

Si selecciona **Personalizado**, especifique la asignación de recursos necesaria para cada réplica.

**Importante:** los requisitos de recursos varían según el modelo. No aplique la configuración de recursos documentada para otro paquete de modelo o fuente.
