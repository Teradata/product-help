Importe los modelos admitidos, revise su estatus actual y abra un modelo para desplegarlo o gestionarlo.

El **Registro de modelos** solo está disponible con Teradata Factory. Debe tener privilegios de administrador para acceder a él y utilizarlo.

## Revisar los modelos registrados


Utilice **Buscar** para localizar un modelo. La tabla incluye:

-   **Nombre:** nombre asignado al modelo.


-   **Alias o ID de modelo:** identificador o alias asociado al modelo.


-   **Versión:** etiqueta de versión asignada al importar el modelo.


-   **Etiquetas:** categorías o etiquetas asociadas al modelo.


-   **Proveedor:** proveedor registrado para el modelo.


-   **Estatus:** estado actual del modelo.


-   **Actualizado:** fecha y hora de la última actualización de la información del modelo.


Seleccione un modelo para revisar sus detalles y las acciones disponibles.

Seleccione **Importar modelo** para importar un modelo admitido desde:

-   **Hugging Face**, cuando Teradata Factory pueda acceder al repositorio de modelos.


-   **Almacenamiento**, cuando el paquete de modelo esté disponible en el almacén de objetos local configurado.
