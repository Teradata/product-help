La página del servidor Teradata Enterprise MCP proporciona acceso rápido a los recursos de Enterprise MCP disponibles en su entorno de AI Studio. Utilice esta página para obtener información de conexión, generar tokens de autenticación, encontrar servidores MCP y acceder a las funciones de gestión del servidor.

La página proporciona la siguiente información y puntos de entrada. Para detalles sobre cómo trabajar con herramientas de MCP y Teradata Enterprise MCP, consulte la [Guía del usuario de Teradata Enterprise MCP](https://docs.teradata.com/access?resourceid=enterprise-mcp-book).

## Endpoint de servidor


Utilice el endpoint del servidor MCP al configurar notebooks, aplicaciones de IA, agentes o clientes MCP externos.

-   **Servidor MCP predeterminado**

    Use la URL del servidor mostrada en la IU para conectarse con el servidor MCP predeterminado.


-   **Servidor MCP desplegado por el administrador**

    Puede conectarse a los servidores MCP desplegados por los administradores en su entorno de AI Studio. Los servidores desplegados por el administrador aparecen listados en la sección **Registro**. Seleccione un servidor para abrir su interfaz de servidor MCP integrada y acceder a las funcionalidades específicas del servidor.

    Si necesita el endpoint del servidor para la configuración del cliente o la automatización, recupérelo de los detalles del servidor en la interfaz o utilizando la API **Listar todos los servidores**. Para obtener más información, consulte [Listar todos los servidores](https://docs.teradata.com/access?resourceid=mcp-srvr-mg-list-servers&utm_source=console&utm_medium=iph).

    Debe conectarse con la red privada donde se despliega AI Studio para acceder a este endpoint.


## Generar un token


Necesitará un token para autenticar las solicitudes. Seleccione un método de autenticación. Para más información, consulte [Autorización, RBAC y autenticación](https://docs.teradata.com/access?resourceid=author-rbac-authen).

## Registro


El Registro muestra los servidores MCP que tiene a su disposición. La lista puede incluir el servidor MCP predeterminado y los servidores MCP personalizados desplegados por los administradores. Seleccione un servidor para abrir su interfaz de servidor MCP integrada.

La interfaz de servidor MCP integrada proporciona acceso a las conexiones, grupos de herramientas personalizados, herramientas, trabajos y configuraciones de autenticación para el servidor seleccionado. Para obtener información detallada sobre cómo trabajar con la interfaz de servidor MCP integrada, consulte [Interfaz de servidor MCP](https://docs.teradata.com/access?resourceid=mcp-server-interface).

**Consejo**: si un servidor no aparece en el Registro, póngase en contacto con su administrador para verificar que el servidor se haya desplegado y esté disponible para su cuenta.

## Gestión de servidores


Si es administrador, seleccione **Servidor MCP** > **Gestión de servidores** para desplegar, configurar, supervisar, escalar, reiniciar y retirar servidores MCP. La gestión de servidores proporciona capacidades de gestión del ciclo de vida para los despliegues de servidores MCP en todo su entorno de AI Studio.

Para obtener información sobre los procedimientos de despliegue y administración, consulte [Gestión del servidor MCP](https://docs.teradata.com/access?resourceid=mcp-server-management).
