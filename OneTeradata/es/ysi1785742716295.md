Puede crear experimentos relacionados con agentes con fines de evaluación.

Proporcione los detalles para los metadatos del experimento, configure los endpoints del agente, y más.

**Metadatos del experimento**

Introduzca un nombre y una descripción únicos para el experimento.

**Agente**

Seleccione el agente y su versión correspondiente que se usará para crear el experimento. Revise todos los detalles antes de continuar. Si es necesario, cambie el agente o la versión para que se ajusten a sus requisitos.

**Configurar endpoints de agente**

Configure el endpoint utilizando Config.json. Puede editar los valores para adaptarlos a sus necesidades. También debe establecer una clave secreta para el experimento.

**Conjunto de datos de evaluación**

Utilice el conjunto de datos existente o cargue un nuevo conjunto de datos para su experimento.

**Seleccione las métricas de evaluación**

Seleccione entre las métricas heurísticas y los jueces LLM disponibles. Si utiliza jueces LLM, deberá configurar el modelo de IA correspondiente.

**Recursos**

Seleccione el grupo de nodos y configure los recursos. Puede utilizar la opción Estándar o Personalizado. Tenga en cuenta que la opción Personalizado consume más recursos.
