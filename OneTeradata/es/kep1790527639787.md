**Estatus**

El estatus determina si el modelo se puede desplegar.

-   **Descargando:** el Centro de modelos de IA está recuperando el modelo.


-   **Listo para el despliegue:** el modelo está disponible para su despliegue.


**Detalles de modelo**

**Desplegar el modelo**

Antes de comenzar:

-   Confirme que el estatus sea **Listo para el despliegue**.


-   Identifique el número de réplicas necesario.


-   Identifique los recursos de computación y GPU necesarios para cada réplica.


-   Obtenga los argumentos personalizados que requiera el modelo.


-   Determine el alias que se utilizará para el modelo en AI Model Gateway.


-   Para un modelo preempaquetado, revise la configuración de recursos y los argumentos de tiempo de ejecución documentados para la fuente y el paquete de modelo.


Seleccione **Desplegar modelo** para abrir el flujo de trabajo de despliegue. Consulte [Desplegar modelo: Configurar recursos](axw1790528514307.md) para ver los siguientes pasos.

**Eliminar el modelo**
