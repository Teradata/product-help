Especifique cómo aparece el modelo desplegado en AI Model Gateway.

Los modelos desplegados se publican en AI Model Gateway. El alias identifica el modelo en la puerta de enlace y no cambia el nombre del modelo en el **Registro de modelos**.

**Elegir un alias de modelo**

-   Habilite **Usar el nombre del modelo real como alias** para publicar el modelo utilizando su nombre.


-   Para usar un nombre diferente, deje la opción **Usar el nombre del modelo real como alias** deshabilitada e introduzca un nombre único en **Alias de modelo**.


Utilice un alias que identifique claramente el modelo en AI Model Gateway.
