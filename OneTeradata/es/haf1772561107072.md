La página Integraciones contiene lo siguiente:

-   Versione su código Git con Gitea: Gitea ofrece alojamiento de repositorios, capacidades de revisión de código, funciones de colaboración en equipo, registros de paquetes e integración de CI/CD. Permite a los equipos de desarrollo gestionar de forma segura el código fuente, realizar un seguimiento de los cambios y colaborar a lo largo de todo el ciclo de vida del desarrollo de software.


-   Cree flujos de trabajo con Airflow: Airflow proporciona un marco de trabajo basado en Python para diseñar flujos de trabajo que se conectan con una amplia gama de tecnologías y servicios. Su interfaz web permite visualizar la ejecución del flujo de trabajo, supervisar el progreso, solucionar problemas y gestionar complejas canalizaciones de procesamiento de datos.


-   Gestione paquetes de Python con devpi: **devpi**, un sistema de gestión de paquetes compatible con PyPI, permite gestionar, versionar y distribuir paquetes de Python dentro del entorno. Con devpi, puede mantener repositorios de paquetes privados, controlar las versiones de los paquetes y optimizar la gestión de dependencias para los flujos de trabajo de desarrollo, pruebas y despliegue.


-   Aproveche más tipos de datos con **Unstructured**: utilice Unstructured para convertir contenido no estructurado y semiestructurado en datos estructurados y listos para la IA. Unstructured procesa documentos, como archivos PDF, presentaciones, páginas web y otras fuentes de contenido, transformándolos en formatos que pueden utilizarse de forma eficiente para búsquedas, recuperación, analíticas y aplicaciones de IA generativa. Esta capacidad ayuda a mejorar la calidad, la precisión y la relevancia de las cargas de trabajo de IA posteriores. Consulte [Integración de Unstructured](https://docs.teradata.com/access?resourceid=vectorcollection-unstructured-integration) para obtener más detalles.
