Revise la configuración completa antes de desplegar el modelo.

Verificar:

-   Modelo para desplegar


-   Número de réplicas


-   Grupo de nodos


-   Recursos asignados a cada réplica


-   Estimación total del consumo de recursos


-   Argumentos personalizados, cuando se proporcionan


-   Alias de AI Model Gateway


Para cambiar una configuración, seleccione **Anterior**, actualice la configuración y vuelva al **Resumen**.

Seleccione **Desplegar** para iniciar el despliegue.

Una vez finalizado el despliegue:

-   El estatus del modelo cambia a **Desplegado**.


-   El estatus de AI Model Gateway cambia a **Publicado**.


-   La página de detalles del modelo muestra el endpoint de inferencia y el nombre del modelo.


-   El modelo estará disponible a través de AI Model Gateway.


A continuación, puede utilizar el modelo a través de AI Model Gateway, verificarlo en el **Área de pruebas** y revisar su actividad en **Observabilidad**.
