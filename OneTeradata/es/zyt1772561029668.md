La fragmentación es el proceso de descomponer documentos o datos grandes en partes más pequeñas y administrables, que son significativas en términos semánticos, denominadas **fragmentos**.

Seleccione **Solo texto** o **Con formato y multimodal**.

**Solo texto**: selecciónelo cuando el contenido de origen sea principalmente texto plano con una estructura predecible, como documentos sencillos, políticas o contratos. Este método de fragmentación es rápido y divide el contenido principalmente por tamaño y reglas configurables, y es posible que no conserve la estructura semántica del documento.

**Con formato y multimodal**: selecciónelo cuando el contenido de origen incluya archivos PDF, formato enriquecido, tablas o imágenes, donde preservar la estructura mejora la calidad de la recuperación. Este método de fragmentación produce fragmentos de mayor calidad para la búsqueda semántica y las cargas de trabajo de RAG.

Puede seleccionar **Rápido** o **Alta resolución** como estrategias de extracción.

De forma predeterminada, cada fragmento contiene 512 caracteres. Si es necesario, puede cambiar el tamaño de este fragmento y seleccionar simultáneamente el encabezado, el pie de página o ambos para su procesamiento.

**Nota**: Al seleccionar el encabezado y el pie se agregan a los datos que se procesan.
