Pase la configuración de tiempo de ejecución de clave-valor al servidor del modelo.

**Antes de comenzar**

Identifique si el modelo seleccionado requiere argumentos personalizados. La configuración de tiempo de ejecución depende del entorno de ejecución y el paquete de modelo.

Para un modelo Hugging Face preempaquetado, utilice los argumentos documentados para ese modelo específico en **Configuración de despliegue de modelos preempaquetados**. Los paquetes NVIDIA NIM no incluyen argumentos de tiempo de ejecución personalizados en la configuración proporcionada.

**Agregar un argumento**

1.  Introduzca el nombre del argumento en **Introducir clave**.


1.  Introduzca el ajuste correspondiente en **Introducir valor**.


1.  Seleccione **Agregar argumento** para agregar otro par clave-valor.


Para eliminar un argumento, seleccione el control de eliminación para el argumento.

Introduzca cada propiedad de tiempo de ejecución documentada como un par clave-valor independiente.

Si el modelo no requiere argumentos personalizados, deje los campos vacíos.

**Importante:** no aplique argumentos de tiempo de ejecución de otro paquete de modelo. La configuración de tiempo de ejecución varía según el modelo y el entorno de ejecución.
