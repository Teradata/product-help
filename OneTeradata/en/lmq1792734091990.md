Administrators use Server Management to deploy MCP servers and review their status, endpoints, and deployment configuration. Server Management is available only to administrators.

To open the page, select **MCP Server** in the navigation panel, and then select **Server Management**.

The **Server Management** page lists the deployed MCP servers and shows the node pool, deployment status, and creation date for each server. You can search the list or select a server to review its details.

Selecting a server opens its details page:

-   The **Overview** tab shows the server status, node pool, site, last update time, and default MCP endpoint.


-   The **Deployment configuration** tab shows the server definition, compute resources, and replica configuration.


Administrators can deploy, review, pause, restart, update, and retire MCP servers. The operations available on the server details page depend on the server status.
