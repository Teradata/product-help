**Before you begin**

-   Confirm that you have permission to import models.


-   Confirm that the model package is available in the configured local object store.


-   For a transferred model, complete the applicable air-gapped package preparation, transfer, verification, and upload workflow.


-   For an NVIDIA NIM model, confirm that the required container image is available in the local container registry.


For NVIDIA NIM, the configured local object store contains the model-cache package. The container image is uploaded separately to the local container registry.

Use the available filters to find a package:

-   **All:** Shows all available models.


-   **Open Source Models:** Shows available open-source models.


-   **NVIDIA Optimized Models:** Shows available NVIDIA-optimized models.


Review the provider, title, profile, latest version, and package size. Select a model, and then select **Import**.

The model appears in **Model Registry**. When the status changes to **Ready to deploy**, you can deploy the model to available GPU resources.
