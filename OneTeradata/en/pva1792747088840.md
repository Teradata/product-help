Resource settings determine the node pool and compute allocation for each MCP server instance.

|Setting|Description|
|--------|------------|
|**Node pool**|Specifies the node pool used by the deployment.|
|**Pool details**|Shows the resource capacity and availability information for the selected node pool.|
|**View node details**|Displays additional information about the selected node pool.|
|**Standard**|Uses the resource allocation displayed on the page.|
|**Custom**|Enables an adjustable resource allocation.|
