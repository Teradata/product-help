**Local files**

Select if you plan to upload text, documents, structured, or tabular data from your machine.

These files can include plain text files, articles, books, user reviews, customer feedback, and internal documentation which are often used for semantic search and Retrieval Augmented Generation (RAG) applications in AI.

You can drag and drop or browse files from your local machine.

**Note**: You can upload up to 10 files (100 MB limit) with the same schema.

**Database tables**

Select if you want to specify the database table and columns. Based on your selection of either Chunks only or Chunks and embeddings, you'll see various selections of tables, columns, and embeddings.

**Unstructured**

AI Studio integrates with Unstructured to support multi-modal data ingestion from a wide range of document and content sources. Unstructured extracts content and metadata from unstructured documents and transforms them into a structured format that can be processed by AI Studio workflows.

Using the Unstructured integration, you can ingest text, document, image, and other supported content types and store the processed output directly in the Teradata Vector Store. This enables the creation of vectorized datasets that support semantic search, RAG pipelines, and other AI applications.

See [Unstructured integration](yrq1780630301285.md) for more details.
