Review the complete configuration before deploying the model.

Verify:

-   Model to be deployed


-   Number of replicas


-   Node pool


-   Resources allocated to each replica


-   Total estimated resource consumption


-   Custom arguments, when provided


-   AI Model Gateway alias


To change a setting, select **Previous**, update the configuration, and return to **Summary**.

Select **Deploy** to start the deployment.

After deployment completes:

-   The model status changes to **Deployed**.


-   The AI Model Gateway status changes to **Published**.


-   The model details page displays the inference endpoint and model name.


-   The model becomes available through AI Model Gateway.


You can then use the model through AI Model Gateway, verify it in **Playground**, and review its activity in **Observability**.
