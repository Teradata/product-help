The Teradata Enterprise MCP Server page provides quick access to the Enterprise MCP resources available in your AI Studio environment. Use this page to get connection information, generate authentication tokens, find MCP servers, and access server management capabilities.

The page provides the following information and entry points. For details on working with Teradata Enterprise MCP and MCP tools, see the [Teradata Enterprise MCP User Guide](https://docs.teradata.com/access?resourceid=enterprise-mcp-book).

## Server endpoint


Use the MCP server endpoint when configuring notebooks, AI applications, agents, or external MCP clients.

-   **Default MCP Server**

    Use the server URL shown in the UI to connect to the default MCP server.


-   **Admin-deployed MCP server**

    You can connect to MCP servers deployed by administrators in your AI Studio environment. Administrator-deployed servers are listed in the **Registry** section. Select a server to open its built-in MCP server interface and access server-specific capabilities.

    If you need the server endpoint for client configuration or automation, retrieve it from the server details in the interface or by using the **List All Servers** API. For more information, see [List All Servers](https://docs.teradata.com/access?resourceid=mcp-srvr-mg-list-servers&utm_source=console&utm_medium=iph).

    You must be connected to the private network where AI Studio is deployed to access this endpoint.


## Generate a token


You will need a token to authenticate requests. Select an authentication method. For more information, see [Authorization, RBAC, and Authentication](https://docs.teradata.com/access?resourceid=author-rbac-authen).

## Registry


Registry lists the MCP servers available to you. The list can include the default MCP server and custom MCP servers deployed by administrators. Select a server to open its built-in MCP server interface.

The built-in MCP server interface provides access to connections, custom tool groups, tools, jobs, and authentication settings for the selected server. For detailed information about working with the built-in MCP server interface, see [MCP Server Interface](https://docs.teradata.com/access?resourceid=mcp-server-interface).

**Tip**: If a server does not appear in Registry, contact your administrator to verify that the server has been deployed and made available to your account.

## Server Management


If you are an administrator, select **MCP Server** > **Server Management** to deploy, configure, monitor, scale, restart, and retire MCP servers. Server Management provides lifecycle management capabilities for MCP server deployments across your AI Studio environment.

For deployment and administration procedures, see [MCP Server Management](https://docs.teradata.com/access?resourceid=mcp-server-management).
