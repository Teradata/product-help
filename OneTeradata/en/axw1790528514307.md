Configure the number of model replicas and the resources assigned to each replica.

Review the model family, name, type, and model size before configuring the deployment.

**Replicas**

From **Replicas**, select the number of model replicas to deploy.

Resource settings apply to each replica.

**Select a node pool**

From **Node pool**, select a node pool that meets the workload and model requirements.

Review **Pool details**, including:

-   Available compute resources


-   Number of nodes


-   Resources per node


-   Current node availability


The displayed resource limits depend on the selected node pool.

**Configure resources**

Choose how to allocate resources to each replica:

-   **Standard:** Uses the displayed default resource allocation.


-   **Custom:** Lets you adjust the resource allocation for each replica.


For a prepackaged model, use the memory, CPU, and GPU values documented for the selected model package and source.

If you select **Custom**, specify the required resource allocation for each replica.

**Important:** Resource requirements vary by model. Do not apply resource settings documented for another model package or source.

Select **Next** to continue to **Custom arguments**. See [Deploy model: Custom arguments](sxt1790528830941.md).
