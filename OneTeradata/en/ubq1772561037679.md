You can choose either Text only or Formatted and multi-modal as chunking methods for your vector collection.

**Text only**: Splits plain text into chunks using size-based or rule-based boundaries. Use it when source content is mostly plain text with predictable structure, such as simple documents, policies, or contracts.

**Formatted and multi-modal**: Uses document layout and content elements, such as, headings, sections, tables, images, to create context-aware chunks. Use it when source content includes PDFs, rich formatting, tables, or images, where preserving structure improves retrieval quality. You can select either **Fast** or **High resolution** as extraction strategies.

**Fast**: Fast extraction is optimized for speed and efficiency. It processes document content quickly with minimal resource consumption, making it suitable for large-scale ingestion of well-structured documents where preserving visual layout and element relationships is not critical. This mode is recommended for text-centric content and applications that primarily require rapid indexing and retrieval.

**High resolution**: High resolution extraction is optimized for accuracy and document structure preservation. It analyzes documents with layout awareness, capturing complex elements such as tables, charts, graphics, and multi-column content while maintaining their relationships within the document. Although it requires more processing resources, this mode is recommended for complex or visually rich documents where maintaining content structure and contextual accuracy is important.
