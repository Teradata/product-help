Review the selected model, its source, import information, current status, and available actions.

**Status**

The status determines whether the model can be deployed.

-   **Downloading:** AI Model Hub is retrieving the model.


-   **Ready to deploy:** The model is available for deployment.


**Model details**

Review the model name, model family, and model type to confirm that you selected the intended model.

**Import details**

Review:

-   **Imported by**


-   **Source**


-   **Imported on**


-   **Imported as version**


**Deploy the model**

Before you begin:

-   Confirm that the status is **Ready to deploy**.


-   Identify the required number of replicas.


-   Identify the compute and GPU resources required for each replica.


-   Obtain any custom arguments required by the model.


-   Determine the alias to use for the model in AI Model Gateway.


-   For a prepackaged model, review the resource configuration and runtime arguments documented for that model package and source.


Select **Deploy model** to open the deployment workflow. See [Deploy model: Configure resources](axw1790528514307.md) for next steps.

**Delete the model**

Select **Delete model** to delete the imported model.
