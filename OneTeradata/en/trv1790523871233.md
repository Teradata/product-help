Import supported models, review their current status, and open a model to deploy or manage it.

**Model registry** is available only with Teradata Factory. You must have administrative privileges to access and use it.

## Review registered models


Use **Search** to locate a model. The table includes:

-   **Name:** Name assigned to the model.


-   **Model ID or alias:** Identifier or alias associated with the model.


-   **Version:** Version label assigned when the model was imported.


-   **Tags:** Categories or labels associated with the model.


-   **Provider:** Provider recorded for the model.


-   **Status:** Current state of the model.


-   **Updated:** Date and time when the model information was last updated.


Select a model to review its details and available actions.

Select **Import model** to import a supported model from:

-   **Hugging Face**, when Teradata Factory can access the model repository.


-   **Storage**, when the model package is available in the configured local object store.
