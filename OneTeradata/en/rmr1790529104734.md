Specify how the deployed model appears in AI Model Gateway.

Deployed models are published to AI Model Gateway. The alias identifies the model in the gateway and does not change the model name in **Model Registry**.

**Choose a model alias**

-   Enable **Use Actual Model Name as Alias** to publish the model by using its model name.


-   To use a different name, leave **Use Actual Model Name as Alias** disabled and enter a unique name in **Model Alias**.


Use an alias that clearly identifies the model in AI Model Gateway.
