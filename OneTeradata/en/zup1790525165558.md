**Before you begin**

-   Confirm that Teradata Factory can access Hugging Face.


-   Review the model information in Hugging Face.


-   Identify the model family, model name, and model type.


-   Confirm that the model format is supported by the configured inference backend.


-   For a gated model, obtain access to the model and create a Hugging Face read token.


**Model details**

-   **Model family:** Enter the model publisher or model family.


-   **Model name:** Enter the model name.


-   **Model type:** Select the type that matches the model operation:

    -   **LLM (text based):** Processes text input and generates text output.


    -   **Embedding (text based):** Converts text into numerical vectors that represent semantic meaning.


    -   **Multimodal LLM (image, video, or audio):** Processes one or more supported media types and generates a response.


    -   **Multimodal embedding (image, video, or audio):** Converts supported media into numerical vectors that represent semantic meaning.


    -   **Reranker:** Scores and reorders retrieved results based on their relevance to a query.


-   **Hugging Face access token:** Enter a Hugging Face read token if the model requires approval or authentication.


-   **Import label:** Enter the version label to assign to the imported model.


Select **Import**.

AI Model Hub adds the model to **Model Registry** and displays its status. **Downloading** indicates that the model is being retrieved. **Ready to deploy** indicates that the model can be deployed.
