Review model information and open the tasks available to you. Dashboard content depends on your role and Teradata offering.

## Dashboard for administrators


Review model, access, and deployment information, and start common administrative tasks. With Teradata Factory, the Dashboard also includes Model Registry information.

**AI Gateway**

The **Recently onboarded models** table shows recently added model endpoints. Use the available model information to compare models by type, provider, version, context length, and rate limit.

-   Select **View all** to open the model list in **AI model gateway**. See [Explore models](eoz1778496909062.md).


-   If you have administrative access, select **Model endpoint** to add a model. See [Add a model](fdy1778502087907.md).


**Model registry**

**Note:** Model Registry is available only with Teradata Factory and requires administrative privileges.

Review the number of registered and deployed models in Model Registry.

-   Select a recently registered model to review its status and details.


-   If you have administrative access, select **Import model** to import a supported model. See [Import model](ecc1790524485875.md).


## Dashboard for data users


Use a virtual API key to view the models assigned to you and browse other models available through AI Model Gateway. If you do not have a virtual API key, contact your AI Model Hub administrator.

**View your assigned models**

1.  Enter the virtual API key in **Enter key**.


1.  Select **Submit**.


The Dashboard displays the models assigned to the virtual API key. The assigned models also appear on the **AI model gateway** tab. See [Explore models](eoz1778496909062.md).

To use a different virtual key, clear the existing key and enter the new key.

**Compare model capacity**

Each model listing includes token information to help you determine whether the model supports your input and response requirements.

-   **Input tokens** indicates how much text you can send in one request. Choose a model with a higher input limit for longer documents or conversation histories.


-   **Output tokens** indicates how much text the model can generate in one response. Choose a model with a higher output limit when you need longer responses.


The Dashboard displays models in a list by default. Use the card-view control to switch to a card view.
