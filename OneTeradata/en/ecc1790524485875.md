Import a supported model from Hugging Face or the configured local object store.

Choose the source based on where the model is available:

-   Select **Hugging Face** when Teradata Factory can access the model repository. See [Import from Hugging Face](zup1790525165558.md).


-   Select **Storage** when the model package is available in the configured local object store. See [Import from Storage](oqb1790527201218.md).


-   For an air-gapped environment, prepare and transfer the package first. Then import it from **Storage**. See the Teradata AI Studio Model Management user guide.
