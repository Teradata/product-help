Pass key-value runtime settings to the model server.

**Before you begin**

Identify whether the selected model requires custom arguments. Runtime settings depend on the model package and runtime.

For a prepackaged Hugging Face model, use the arguments documented for that specific model in **Prepackaged Model Deployment Settings**. NVIDIA NIM packages do not include custom runtime arguments in the supplied configuration.

**Add an argument**

1.  Enter the argument name in **Enter key**.


1.  Enter the corresponding setting in **Enter value**.


1.  Select **Add argument** to add another key-value pair.


To remove an argument, select the delete control for that argument.

Enter each documented runtime property as a separate key-value pair.

If the model does not require custom arguments, leave the fields empty.

**Important:** Do not apply runtime arguments from another model package. Runtime settings vary by model and runtime.

Select **Next** to continue to **Publish to AI Model Gateway**. See [Deploy model: Publish to AI model gateway](rmr1790529104734.md).
