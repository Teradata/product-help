You can create experiments on agents for evaluation purpose.

Provide the details for experiment metadata, configure agent endpoints, and others.

**Experiment metadata**

Enter unique name and description for the experiment.

**Agent**

Select the agent and its corresponding version to use to create the experiment. Go through the details before proceeding further. If required, change the agent or version to match your requirements.

**Configure agent endpoints**

Configure the endpoint using Config.json. You can edit the values in it to suit your requirements. You must also set a secret key for the experiment.

**Eval dataset**

Use the existing dataset or upload new dataset for your expirement.

**Select evaluation metrics**

Select from the available Heuristic metrics and LLM Judges. If using LLM Judges, you have to configure the respective AI model.

**Resources**

Select the Node pool and configure resources. You can use Standard or Custom. Note that Custom uses more resources.
