The deployment summary provides the server name and the selected resource configuration. Review the summary before deploying the MCP server.

|Information|Description|
|------------|------------|
|**Deployment metadata**|Shows the deployment name.|
|**Node pool**|Shows the selected node pool.|
|**CPU per instance**|Shows the CPU allocated to each MCP server instance.|
|**Memory per instance**|Shows the memory allocated to each MCP server instance.|
|**Max number of replicas**|Shows the configured maximum number of replicas.|
|**Total resource consumption estimate**|Shows the estimated total CPU and memory consumption for the deployment configuration.|
