AI Studio integrates with **Unstructured** to ingest content from documents, images, and 35+ supported file types. Unstructured extracts content and metadata, converts it into a structured format, and stores the processed output in the **Teradata Vector Store** for semantic search, RAG workflows, and other AI applications.

**Destination Selection**

When configuring connectors, select the destination based on your data type:

**Teradata Vector Store**: For vector-based workflows.

**Teradata Database**: For non-vector (relational) workflows.

**Capabilities**

Ingest pre-parsed data in **CSV, Parquet, JSON, JSONL, NDJSON, and LDJSON** formats directly into Vector Store.

Map text and embedding fields directly to a collection during ingestion.

Use **High-Res** and **Fast** processing strategies with Unstructured.

Use the **Chunk-by-Title** chunking strategy with Unstructured.

Use **direct Vector Store ingestion** for data that already contains precomputed embeddings.

**Note:** Vector workflows require more processing resources than structured data ingestion.

**Limitations**

Precomputed embeddings in JSON or CSV files are not preserved by the Unstructured processing pipeline.

Embeddings processed through partitioning and chunking may be modified or fragmented.

Ingesting precomputed embeddings through the Unstructured pipeline is not supported.

Search results may vary between Unstructured and Vector store ingestion workflows due to differences in processing, extraction, and chunking.

Matching embedding models alone does not guarantee identical search results.

Unstructured Open Source provides fewer parsing, extraction, and chunking options than direct implementation.

Image and table extraction quality may differ between Open Source and direct workflows.

Open Source uses CPU-based extraction and may be slower than direct VLM-based extraction.

Differences in parsing, chunking, and extraction settings can affect collection content and retrieval results.

See [Unstructured Integration](https://docs.teradata.com/access?resourceid=vectorcollection-unstructured-integration) for more details.
