Replicas are container instances that run the MCP server in an AWS or Azure Kubernetes cluster. The minimum number establishes the number of instances available when the deployment starts. As traffic increases, Kubernetes can add instances up to the configured maximum.

Set the minimum and maximum values according to the number of instances that the deployment requires. A higher maximum allows Kubernetes to add more server instances when traffic increases. The deployment does not scale beyond the configured maximum.

|Setting|Description|
|--------|------------|
|**Minimum number of MCP instances**|Sets the number of MCP server instances available when the deployment starts.|
|**Maximum number of MCP instances**|Sets the highest number of MCP server instances that Kubernetes can add as traffic increases.|
