Monitor AI model usage across your organization. Review consumption patterns, track how models and virtual keys are used over time, and identify optimization opportunities.

-   **Total requests**: Total number of requests sent to models in the selected reporting period.

    When to use it: Measure overall usage and changes in request volume.


-   **Completion tokens**: Total tokens generated by models as responses.

    When to use it: Understand output verbosity and response size.


-   **Prompt tokens**: Total tokens sent as input prompts to models.

    When to use it: Analyze input complexity and prompt engineering efficiency.


-   **Successful requests**: Requests processed successfully with valid responses.

    When to use it: Assess system reliability and model availability.


-   **Failed requests**: Requests that returned errors such as authentication issues, rate limits, or timeouts.

    When to use it: Identify stability, configuration, or integration issues.


-   **Models**: Number of models onboarded to AI Model Hub.

    When to use it: Compare with Top models used to identify onboarded models with no traffic.


-   **Keys**: Number of distinct keys observed in usage logs within the selected timeframe. This value might include deleted keys.

    When to use it: Understand how many keys generated usage during the selected timeframe.


-   **Top models used**: The five models with the highest total token consumption, including prompt and completion tokens.

    When to use it: Identify the most frequently consumed models.


-   **Top consuming keys**: The five keys with the highest total token consumption, identified by key alias or masked key.

    When to use it: Identify keys with high token consumption.


-   **Requests over time**: Request trends for the selected reporting period.

    When to use it: Identify spikes, drops, or recurring usage patterns.

    -   **Daily**: Last 30 days


    -   **Weekly**: Last 12 weeks


    -   **Monthly**: Last 12 months


    -   **Quarterly**: Last 8 quarters


    -   **Yearly**: Last 3 years

    Dates are displayed in UTC.
