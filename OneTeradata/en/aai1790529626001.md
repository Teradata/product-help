Review the deployed model, its AI Model Gateway publication status, endpoint information, deployment configuration, and import information.

**Deployment status**

-   **Deployed** indicates that model deployment completed.


-   **Published** indicates that the deployed model was published to AI Model Gateway.


Select **View details** to review the corresponding AI Model Gateway model information.

**Endpoint details**

-   **Endpoint:** Inference endpoint for the deployed model.


-   **Model name:** Name used to reference the model through AI Model Gateway.


Use the copy controls to copy the displayed values.

**Deployment details**

Review the resources and configuration used for the deployment.

**Model details**

Review the model name, source, model family, and model type.

**Import details**

Review the model source, import date, imported version, and importer information.

## Retire the model


Retire the deployed model when it is no longer required for inference.

**Before you begin**

-   Confirm that applications and users no longer require the deployed model.


-   Confirm that removing the model from AI Model Gateway will not interrupt an active workload.


-   Record any endpoint or deployment information required for operational tracking.


1.  Review the model name and deployment details.


1.  Select **Retire**.


1.  Review the confirmation that retiring the model undeploys it and removes it from AI Model Gateway.


1.  Select **Retire** to confirm.


Retiring the model:

-   Undeploys the model.


-   Removes the model from AI Model Gateway.


-   Keeps the imported model in Model Registry.
