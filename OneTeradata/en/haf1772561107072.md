The Integrations page contains:

-   Version your Git code with Gitea: Gitea provides repository hosting, code review capabilities, team collaboration features, package registries, and CI/CD integration. It enables development teams to securely manage source code, track changes, and collaborate throughout the software development lifecycle.


-   Create workflows with Airflow: Airflow provides a Python-based framework for designing workflows that connect with a wide range of technologies and services. Its web-based interface allows you to visualize workflow execution, monitor progress, troubleshoot issues, and manage complex data processing pipelines.


-   Manage Python packages with devpi: The **devpi**, a PyPI-compatible package management system enables you to manage, version, and distribute Python packages within your environment. With devpi, you can maintain private package repositories, control package versions, and streamline dependency management for development, testing, and deployment workflows.


-   Leverage more data types with Unstructured: Use **Unstructured** to convert unstructured and semi-structured content into structured, AI-ready data. Unstructured processes documents such as PDFs, presentations, web pages, and other content sources, transforming them into formats that can be efficiently used for search, retrieval, analytics, and generative AI applications. This capability helps improve the quality, accuracy, and relevance of downstream AI workloads. See [Unstructured Integration](https://docs.teradata.com/access?resourceid=vectorcollection-unstructured-integration) for more details.
