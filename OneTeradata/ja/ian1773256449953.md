Teradata Enterprise MCP Serverのページでは、AI Studio環境で利用可能なEnterprise MCPリソースにすばやくアクセスできます。このページでは、接続情報の取得、認証トークンの生成、MCPサーバーの検索、サーバー管理機能へのアクセスを行うことができます。

このページでは、以下の情報とエントリ ポイントが提供されます。Teradata Enterprise MCPおよびMCPツールの詳細な取り扱い方法については、[Teradata Enterprise MCPユーザー ガイド](https://docs.teradata.com/access?resourceid=enterprise-mcp-book)を参照してください。

## サーバー エンドポイント


Notebook、AIアプリケーション、エージェント、または外部MCPクライアントを設定する際は、MCPサーバーのエンドポイントを使用してください。

-   **既定のMCPサーバー**

    既定のMCPサーバーに接続するには、画面に表示されているサーバーURLを使用してください。


-   **管理者がデプロイしたMCPサーバー**

    AI Studio環境の管理者によってデプロイされたMCPサーバーに接続できます。管理者によって展開されたサーバーは、 **レジストリ** セクションに一覧表示されます。サーバーを選択すると、そのサーバーに組み込まれているMCPサーバー インターフェースが開き、サーバー固有の機能にアクセスできます。

    クライアントの設定や自動化のためにサーバー エンドポイントが必要な場合は、インターフェースのサーバー詳細から取得するか、 **List All Servers** API を使用してください。詳細については、[List All Servers](https://docs.teradata.com/access?resourceid=mcp-srvr-mg-list-servers&utm_source=console&utm_medium=iph)を参照してください。

    このエンドポイントにアクセスするには、AI Studioがデプロイされているプライベート ネットワークに接続している必要があります。


## トークンを生成


リクエストを認証するにはトークンが必要です。認証方法を選択します。詳細は[認可、RBAC、および認証](https://docs.teradata.com/access?resourceid=author-rbac-authen)を参照してください。

## レジストリ


レジストリには、利用可能なMCPサーバーの一覧が表示されます。このリストには、既定のMCPサーバーと、管理者がデプロイしたカスタムMCPサーバーが含まれる場合があります。サーバーを選択すると、そのサーバーに組み込まれているMCPサーバー インターフェースが開きます。

内蔵のMCPサーバー インターフェースを使用すると、選択したサーバーの接続、カスタム ツール グループ、ツール、ジョブ、認証設定にアクセスできます。組み込みの MCP サーバー インターフェイスの操作に関する詳細については、 [MCP サーバー インターフェイス](https://docs.teradata.com/access?resourceid=mcp-server-interface)を参照してください。

**ヒント**: サーバーがレジストリに表示されない場合は、管理者に連絡して、サーバーがデプロイされ、アカウントで利用可能になっていることを確認してください。

## サーバー管理


管理者の場合は、MCPサーバーのデプロイ、構成、監視、スケーリング、再起動、廃止を行うには、**MCPサーバー**>**サーバー管理**を選択してください。サーバー管理では、AI Studio環境全体にわたるMCPサーバーのデプロイに対するライフサイクル管理機能を提供します。

デプロイおよび管理手順については、[MCPサーバー管理](https://docs.teradata.com/access?resourceid=mcp-server-management)を参照してください。
