Konfigurieren Sie die Anzahl der Modellreplikate und die Ressourcen, die jedem Replikat zugewiesen werden.

Überprüfen Sie vor der Konfiguration der Bereitstellung die Modellfamilie, den Namen, den Typ und die Modellgröße.

**Replikate**

Wählen Sie unter **Replikate** die Anzahl der bereitzustellenden Modellreplikate aus.

Ressourceneinstellungen gelten für jedes Replikat.

**Knoten-Pool auswählen**

Wählen Sie unter **Knoten-Pool** einen Knoten-Pool aus, der die Arbeitslast- und Modellanforderungen erfüllt.

Überprüfen Sie **Pool-Details**, einschließlich:

-   Verfügbare Computing-Ressourcen


-   Anzahl der Knoten


-   Ressourcen pro Knoten


-   Aktuelle Knotenverfügbarkeit


Die angezeigten Ressourcengrenzen hängen vom ausgewählten Knoten-Pool ab.

**Ressourcen konfigurieren**

Wählen Sie aus, wie die Ressourcen den einzelnen Replikaten zugewiesen werden sollen:

-   **Standard:** Verwendet die angezeigte Standardressourcenzuweisung.


-   **Benutzerdefiniert:** Hiermit können Sie die Ressourcenzuweisung für jedes Replikat anpassen.


Verwenden Sie für ein vorkonfiguriertes Modell die für das ausgewählte Modellpaket und die Quelle dokumentierten Werte für Speicher, CPU und GPU.

Wenn Sie **Benutzerdefiniert** auswählen, geben Sie die erforderliche Ressourcenzuweisung für jedes Replikat an.

**Wichtig:** Ressourcenanforderungen variieren je nach Modell. Wenden Sie keine Ressourceneinstellungen an, die für ein anderes Modellpaket oder eine andere Quelle dokumentiert sind.

Wählen Sie **Weiter** aus, um mit **Benutzerdefinierte Argumente** fortzufahren. Siehe [Modell bereitstellen: Benutzerdefinierte Argumente](sxt1790528830941.md).
