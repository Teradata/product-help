Sehen Sie sich die Modellinformationen an und öffnen Sie die Ihnen zur Verfügung stehenden Aufgaben. Der Inhalt des Dashboards hängt von Ihrer Rolle und dem Teradata-Angebot ab.

## Dashboard für Administratoren


Überprüfen Sie Modell-, Zugriffs- und Bereitstellungsinformationen und beginnen Sie mit allgemeinen administrativen Aufgaben. Mit Teradata Factory enthält das Dashboard auch Informationen zur Modellregistrierung.

**KI-Gateway**

Die Tabelle **Kürzlich eingebundene Modelle** zeigt die zuletzt hinzugefügten Modellendpunkte an. Nutzen Sie die verfügbaren Modellinformationen, um Modelle nach Typ, Anbieter, Version, Kontextlänge und Ratenbegrenzung zu vergleichen.

-   Wählen Sie **Alle anzeigen**, um die Modellliste in **KI-Modell-Gateway** zu öffnen. Siehe [Modelle erkunden](eoz1778496909062.md).


-   Wenn Sie über Administratorrechte verfügen, wählen Sie **Modellendpunkt**, um ein Modell hinzuzufügen. Siehe [Modell hinzufügen](fdy1778502087907.md).


**Modellregistrierung**

**Hinweis:** Die Modellregistrierung ist nur mit Teradata Factory verfügbar und erfordert Administratorrechte.

Überprüfen Sie die Anzahl der registrierten und bereitgestellten Modelle in der Modellregistrierung.

-   Wählen Sie ein kürzlich registriertes Modell aus, um dessen Status und Details einzusehen.


-   Wenn Sie über Administratorrechte verfügen, wählen Sie **Modell importieren** aus, um ein unterstütztes Modell zu importieren. Siehe [Modell importieren](ecc1790524485875.md).


## Dashboard für Datennutzer


Verwenden Sie einen virtuellen API-Schlüssel, um die Ihnen zugewiesenen Modelle anzuzeigen und andere über AI Model Gateway verfügbare Modelle zu durchsuchen. Falls Sie keinen virtuellen API-Schlüssel besitzen, wenden Sie sich an Ihren AI Model Hub-Administrator.

**Ihre zugewiesenen Modelle anzeigen**

1.  Geben Sie den virtuellen API-Schlüssel unter **Schlüssel eingeben** ein.


1.  Wählen Sie **Übermitteln**.


Das Dashboard zeigt die dem virtuellen API-Schlüssel zugewiesenen Modelle an. Die zugewiesenen Modelle werden auch auf der Registerkarte **KI-Modell-Gateway** angezeigt. Siehe [Modelle erkunden](eoz1778496909062.md).

Um einen anderen virtuellen Schlüssel zu verwenden, löschen Sie den vorhandenen Schlüssel und geben Sie den neuen Schlüssel ein.

**Modellkapazität vergleichen**

Jede Modellauflistung enthält Token-Informationen, die Ihnen helfen festzustellen, ob das Modell Ihre Eingabe- und Antwortanforderungen erfüllt.

-   **Eingabetokens** geben an, wie viel Text Sie in einer Anfrage senden können. Wählen Sie ein Modell mit höherem Eingabelimit für längere Dokumente oder Konversationsverläufe.


-   **Ausgabetoken** geben an, wie viel Text das Modell in einer Antwort generieren kann. Wählen Sie ein Modell mit höherem Ausgabelimit, wenn Sie längere Antworten benötigen.


Das Dashboard zeigt Modelle standardmäßig in einer Liste an. Verwenden Sie die Kartenansicht-Steuerung, um zur Kartenansicht zu wechseln.
