**Bevor Sie beginnen**

-   Vergewissern Sie sich, dass Teradata Factory auf Hugging Face zugreifen kann.


-   Lesen Sie die Modellinformationen in Hugging Face.


-   Identifizieren Sie die Modellfamilie, den Modellnamen und den Modelltyp.


-   Vergewissern Sie sich, dass das Modellformat vom konfigurierten Inferenz-Backend unterstützt wird.


-   Bei einem Modell mit Gate muss der Zugriff auf das Modell erlangt und ein Hugging Face-Lesetoken erstellt werden.


**Modelldetails**

-   **Modellfamilie:** Geben Sie ein, von welcher Stelle das Modell veröffentlicht wurde, oder die Modellfamilie.


-   **Modellname:** Geben Sie den Modellnamen ein.


-   **Modelltyp:** Wählen Sie den Typ aus, der der Modelloperation entspricht:

    -   **LLM (textbasiert):** Verarbeitet Texteingaben und erzeugt Textausgaben.


    -   **Einbettung (textbasiert):** Wandelt Text in numerische Vektoren um, die die semantische Bedeutung repräsentieren.


    -   **Multimodales LLM (Bild, Video oder Audio):** Verarbeitet einen oder mehrere unterstützte Medientypen und generiert eine Antwort.


    -   **Multimodale Einbettung (Bild, Video oder Audio):** Konvertiert unterstützte Medien in numerische Vektoren, die die semantische Bedeutung repräsentieren.


    -   **Reranker:** Bewertet und ordnet die abgerufenen Ergebnisse neu, basierend auf ihrer Relevanz für eine Abfrage.


-   **Hugging Face-Zugriffstoken:** Geben Sie ein Hugging Face-Lesetoken ein, wenn das Modell eine Genehmigung oder Authentifizierung erfordert.


-   **Importbezeichnung:** Geben Sie die Versionsbezeichnung ein, die dem importierten Modell zugewiesen werden soll.


Wählen Sie **Importieren**.

AI Model Hub fügt das Modell zur **Modellregistrierung** hinzu und zeigt dessen Status an. **Wird heruntergeladen** zeigt an, dass das Modell abgerufen wird. **Bereit zur Bereitstellung** zeigt an, dass das Modell eingesetzt werden kann.
