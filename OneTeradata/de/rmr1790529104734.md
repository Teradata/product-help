Legen Sie fest, wie das bereitgestellte Modell im AI Model Gateway angezeigt wird.

Die bereitgestellten Modelle werden im AI Model Gateway veröffentlicht. Der Alias identifiziert das Modell im Gateway und ändert nicht den Modellnamen in der **Modellregistrierung**.

**Modellalias wählen**

-   Aktivieren Sie die Option **Tatsächlichen Modellnamen als Alias verwenden**, um das Modell unter Verwendung seines Modellnamens zu veröffentlichen.


-   Um einen anderen Namen zu verwenden, lassen Sie die Option **Tatsächlichen Modellnamen als Alias verwenden** deaktiviert und geben Sie im Feld **Modellalias** einen eindeutigen Namen ein.


Verwenden Sie einen Alias, der das Modell im AI Model Gateway eindeutig identifiziert.

Wählen Sie **Weiter**, um zur **Zusammenfassung** zu gelangen. Siehe [Modell bereitstellen: Zusammenfassung](mid1790529307573.md).
