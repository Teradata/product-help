Importieren Sie ein unterstütztes Modell aus Hugging Face oder dem konfigurierten lokalen Objektspeicher.

Wählen Sie die Quelle anhand der Verfügbarkeit des Modells aus:

-   Wählen Sie **Hugging Face**, wenn Teradata Factory auf das Modell-Repository zugreifen kann. Siehe [Import von Hugging Face](zup1790525165558.md).


-   Wählen Sie **Speicher**, wenn das Modellpaket im konfigurierten lokalen Objektspeicher verfügbar ist. Siehe [Import aus dem Speicher](oqb1790527201218.md).


-   Bei einer Air-Gap-Umgebung muss das Paket zuerst vorbereitet und transportiert werden. Importieren Sie es dann aus dem **Speicher**. Siehe das Benutzerhandbuch für die Modellverwaltung von Teradata AI Studio.
