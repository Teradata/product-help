Überprüfen Sie das ausgewählte Modell, seine Quelle, Importinformationen, den aktuellen Status und die verfügbaren Aktionen.

**Status**

Der Status bestimmt, ob das Modell eingesetzt werden kann.

-   **Wird heruntergeladen:** AI Model Hub ruft das Modell ab.


-   **Bereit zur Bereitstellung:** Das Modell ist zur Bereitstellung verfügbar.


**Modelldetails**

Überprüfen Sie den Modellnamen, die Modellfamilie und den Modelltyp, um sicherzustellen, dass Sie das gewünschte Modell ausgewählt haben.

**Importdetails**

Überprüfen:

-   **Importiert von**


-   **Quelle**


-   **Importiert am**


-   **Importiert als Version**


**Modell bereitstellen**

Bevor Sie beginnen:

-   Bestätigen Sie, dass der Status **Bereit zur Bereitstellung** lautet.


-   Ermitteln Sie die erforderliche Anzahl an Replikaten.


-   Ermitteln Sie die für jedes Replikat benötigten Computing- und GPU-Ressourcen.


-   Rufen Sie vom Modell benötigte benutzerdefinierte Argumente ab.


-   Bestimmen Sie den Alias, der für das Modell im AI Model Gateway verwendet werden soll.


-   Überprüfen Sie bei einem vorkonfigurierten Modell die Ressourcenkonfiguration und die Laufzeitargumente, die für dieses Modellpaket und die Quelle dokumentiert sind.


Wählen Sie **Modell bereitstellen** aus, um den Arbeitsablauf für die Bereitstellung zu öffnen. Siehe [Modell bereitstellen: Ressourcen konfigurieren](axw1790528514307.md) für die nächsten Schritte.

**Modell löschen**

Wählen Sie **Modell löschen**, um das importierte Modell zu löschen.
