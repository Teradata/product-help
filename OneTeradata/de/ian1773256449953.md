Die Teradata Enterprise MCP Server-Seite bietet schnellen Zugriff auf die in Ihrer AI Studio-Umgebung verfügbaren Enterprise MCP-Ressourcen. Auf dieser Seite können Sie Verbindungsinformationen abrufen, Authentifizierungstoken generieren, MCP-Server finden und auf Serververwaltungsfunktionen zugreifen.

Die Seite bietet die folgenden Informationen und Einstiegspunkte. Weitere Informationen zur Arbeit mit Teradata Enterprise MCP und MCP-Tools finden Sie im [Benutzerhandbuch für Teradata Enterprise MCP](https://docs.teradata.com/access?resourceid=enterprise-mcp-book).

## Serverendpunkt


Verwenden Sie den MCP-Server-Endpunkt bei der Konfiguration von Notebooks, KI-Anwendungen, Agenten oder externen MCP-Clients.

-   **Standardmäßiger MCP-Server**

    Verwenden Sie die auf der Benutzeroberfläche angezeigte Server-URL, um eine Verbindung mit dem standardmäßigen MCP-Server herzustellen.


-   **Vom Administrator bereitgestellter MCP-Server**

    Sie können eine Verbindung zu MCP-Servern herstellen, die von Administratoren in Ihrer AI Studio-Umgebung bereitgestellt werden. Die vom Administrator bereitgestellten Server werden im Abschnitt **Registrierung** aufgelistet. Wählen Sie einen Server aus, um dessen integrierte MCP-Serverschnittstelle zu öffnen und auf serverspezifische Funktionen zuzugreifen.

    Falls Sie den Serverendpunkt für die Clientkonfiguration oder -automatisierung benötigen, rufen Sie ihn über die Serverdetails in der Benutzeroberfläche oder mithilfe der API **Alle Server auflisten** ab. Weitere Informationen finden Sie unter [Alle Server auflisten](https://docs.teradata.com/access?resourceid=mcp-srvr-mg-list-servers&utm_source=console&utm_medium=iph).

    Sie müssen mit dem privaten Netzwerk verbunden sein, in dem AI Studio bereitgestellt ist, um auf diesen Endpunkt zuzugreifen.


## Ein Token generieren


Sie benötigen ein Token, um Anfragen zu authentifizieren. Wählen Sie eine Authentifizierungsmethode aus. Weitere Informationen finden Sie unter [Autorisierung, RBAC und Authentifizierung](https://docs.teradata.com/access?resourceid=author-rbac-authen).

## Registrierung


Die Registrierung listet die für Sie verfügbaren MCP-Server auf. Die Liste kann den Standard-MCP-Server und von Administratoren bereitgestellte benutzerdefinierte MCP-Server enthalten. Wählen Sie einen Server aus, um dessen integrierte MCP-Serverschnittstelle zu öffnen.

Die integrierte MCP-Serverschnittstelle ermöglicht den Zugriff auf Verbindungen, benutzerdefinierte Tool-Gruppen, Tools, Aufträge und Authentifizierungseinstellungen für den ausgewählten Server. Ausführliche Informationen zur Arbeit mit der integrierten MCP-Serverschnittstelle finden Sie unter [MCP-Serverschnittstelle](https://docs.teradata.com/access?resourceid=mcp-server-interface).

**Tipp**: Falls ein Server nicht in der Registrierung angezeigt wird, wenden Sie sich an Ihren Administrator, um zu überprüfen, ob der Server bereitgestellt und Ihrem Konto zur Verfügung gestellt wurde.

## Serververwaltung


Wenn Sie Administrator sind, wählen Sie **MCP-Server** > **Serververwaltung**, um MCP-Server bereitzustellen, zu konfigurieren, zu überwachen, zu skalieren, neu zu starten und stillzulegen. Serververwaltung bietet Funktionen für das Lebenszyklusmanagement von MCP-Serverbereitstellungen in Ihrer AI Studio-Umgebung.

Informationen zu Bereitstellungs- und Administrationsverfahren finden Sie unter [MCP-Serververwaltung](https://docs.teradata.com/access?resourceid=mcp-server-management).
