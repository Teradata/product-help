Sie können Experimente mit Agenten zu Evaluierungszwecken erstellen.

Geben Sie die Details für die Experimentmetadaten an, konfigurieren Sie Agentenendpunkte und mehr.

**Metadaten für Experiment**

Geben Sie einen eindeutigen Namen und eine Beschreibung für das Experiment ein.

**Agent**

Wählen Sie den Agenten und die zugehörige Version aus, die zum Erstellen des Experiments verwendet werden sollen. Gehen Sie die Details durch, bevor Sie fortfahren. Ändern Sie gegebenenfalls den Agenten oder die Version, um sie Ihren Anforderungen anzupassen.

**Agentenendpunkte konfigurieren**

Konfigurieren Sie den Endpunkt mithilfe der Datei Config.json. Sie können die Werte darin an Ihre Anforderungen anpassen. Sie müssen außerdem einen geheimen Schlüssel für das Experiment festlegen.

**Bewertungs-Dataset**

Verwenden Sie das vorhandene Dataset oder laden Sie ein neues Dataset für Ihr Experiment hoch.

**Bewertungsmetriken auswählen**

Wählen Sie aus den verfügbaren heuristischen Metriken und LLM-gestützten Bewertungen aus. Bei Verwendung von LLM-gestützten Bewertungen müssen Sie das jeweilige KI-Modell konfigurieren.

**Ressourcen**

Wählen Sie den Knoten-Pool aus und konfigurieren Sie Ressourcen. Sie können „Standard“ oder „Benutzerdefiniert“ verwenden. Beachten Sie, dass „Benutzerdefiniert“ mehr Ressourcen nutzt.
