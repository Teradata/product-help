**Bevor Sie beginnen**

-   Vergewissern Sie sich, dass Sie die Berechtigung zum Importieren von Modellen haben.


-   Vergewissern Sie sich, dass das Modellpaket im konfigurierten lokalen Objektspeicher verfügbar ist.


-   Führen Sie für ein übertragenes Modell den entsprechenden Arbeitsablauf für die Vorbereitung, Übertragung, Verifizierung und den Upload des Air-Gap-Pakets durch.


-   Prüfen Sie bei einem NVIDIA NIM-Modell, ob das erforderliche Container-Image in der lokalen Container-Registrierung verfügbar ist.


Bei NVIDIA NIM enthält der konfigurierte lokale Objektspeicher das Modellcache-Paket. Das Container-Image wird separat in die lokale Container-Registrierung hochgeladen.

Nutzen Sie die verfügbaren Filter, um ein Paket zu finden:

-   **Alle:** Zeigt alle verfügbaren Modelle an.


-   **Open-Source-Modelle:** Zeigt verfügbare Open-Source-Modelle an.


-   **NVIDIA-optimierte Modelle:** Zeigt verfügbare NVIDIA-optimierte Modelle an.


Prüfen Sie Anbieter, Titel, Profil, neueste Version und Paketgröße. Wählen Sie ein Modell aus und klicken Sie dann auf **Importieren**.

Das Modell erscheint in der **Modellregistrierung**. Sobald sich der Status in **Bereit zur Bereitstellung** ändert, können Sie das Modell auf den verfügbaren GPU-Ressourcen bereitstellen.
