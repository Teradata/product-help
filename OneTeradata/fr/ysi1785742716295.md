Vous pouvez créer des expériences sur des agents à des fins d'évaluation.

Fournissez les détails relatifs aux métadonnées de l'expérience, configurez les points de terminaison de l'agent, et plus encore.

**Métadonnées de l'expérience**

Saisissez un nom unique et une description pour l'expérience.

**Agent**

Sélectionnez l'agent et sa version correspondante à utiliser pour créer l'expérience. Examinez les détails avant de poursuivre. Si nécessaire, modifiez l'agent ou la version pour qu'ils correspondent à vos besoins.

**Configurer les points de terminaison de l'agent**

Configurez le point de terminaison à l'aide de Config.json. Vous pouvez modifier les valeurs qui y figurent en fonction de vos besoins. Vous devez également définir une clé secrète pour l'expérience.

**Ensemble de données d'évaluation**

Utilisez l'ensemble de données existant ou chargez un nouvel ensemble de données pour votre expérience.

**Sélectionner les mesures d'évaluation**

Sélectionnez parmi les mesures heuristiques et les juges LLM disponibles. Si vous utilisez les juges LLM, vous devez configurer le modèle d'IA correspondant.

**Ressources**

Sélectionnez le pool de nœuds et configurez les ressources. Vous pouvez utiliser l'option Standard ou Personnalisé. Notez que l'option Personnalisé utilise davantage de ressources.
