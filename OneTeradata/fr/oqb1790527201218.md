**Avant de commencer**

-   Confirmez que vous disposez de l'autorisation d'importer des modèles.


-   Confirmez que le module du modèle est disponible dans le magasin d'objets local configuré.


-   Pour un modèle transféré, effectuez le flux de travail applicable de préparation, de transfert, de vérification et de chargement du module isolé.


-   Pour un modèle NVIDIA NIM, vérifiez que l'image de conteneur requise est disponible dans le registre de conteneurs local.


Pour NVIDIA NIM, le magasin d'objets local configuré contient le module de cache de modèles. L'image de conteneur est chargée séparément sur le registre de conteneurs local.

Recherchez un module à l'aide des filtres disponibles :

-   **Tous :** affiche tous les modèles disponibles.


-   **Modèles open source :** affiche les modèles open source disponibles.


-   **Modèles optimisés par NVIDIA :** affiche les modèles optimisés par NVIDIA disponibles.


Examinez le fournisseur, le titre, le profil, la dernière version et la taille du module. Sélectionnez un modèle, puis **Importer**.

Le modèle s'affiche dans **Registre de modèles**. Lorsque l'état est redéfini sur **Prêt à être déployé**, vous pouvez déployer le modèle sur les ressources GPU disponibles.
