Examinez le modèle sélectionné, sa source, les informations d'importation, son état actuel et les actions disponibles.

**État**

L'état détermine si le modèle peut être déployé.

-   **Téléchargement en cours :** la plateforme de modèles d'IA récupère le modèle.


-   **Prêt à être déployé :** le modèle est disponible pour le déploiement.


**Détails du modèle**

Examinez le nom du modèle, la famille de modèles et le type de modèle pour vérifier que vous avez sélectionné le modèle souhaité.

**Détails de l'importation**

Examen :

-   **Importé par**


-   **Source**


-   **Importé le**


-   **Importé en tant que version**


**Déployer le modèle**

Avant de commencer :

-   Vérifiez que l'état est **Prêt à être déployé**.


-   Identifiez le nombre de réplicas requis.


-   Identifiez les ressources de calcul et GPU nécessaires pour chaque réplica.


-   Obtenez tous les arguments personnalisés requis par le modèle.


-   Déterminez l'alias à utiliser pour le modèle dans la passerelle de modèles d'IA.


-   Pour un modèle prêt à l'emploi, examinez la configuration des ressources et les arguments d'exécution documentés pour ce module et cette source de modèle.


Sélectionnez **Déployer un modèle** pour ouvrir le flux de travail de déploiement. Reportez-vous à la section [Déployer un modèle : configurer les ressources](axw1790528514307.md) pour connaître les étapes suivantes.

**Supprimer le modèle**

Sélectionnez **Supprimer le modèle** pour supprimer le modèle importé.
