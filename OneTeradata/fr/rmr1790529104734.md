Spécifiez le mode d'affichage du modèle déployé dans la passerelle de modèles d'IA.

Les modèles déployés sont publiés sur la passerelle de modèles d'IA. L'alias identifie le modèle dans la passerelle et ne modifie pas le nom du modèle dans **Registre de modèles**.

**Choisir un alias de modèle**

-   Activez l'option **Utiliser le nom réel du modèle comme alias** pour publier le modèle en utilisant son nom.


-   Pour utiliser un autre nom, laissez l'option **Utiliser le nom réel du modèle comme alias** désactivée et saisissez un nom unique dans **Alias de modèle**.


Utilisez un alias qui identifie clairement le modèle dans la passerelle de modèles d'IA.
