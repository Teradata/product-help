Examinez le modèle déployé, son état de publication sur la passerelle de modèles d'IA, les informations sur le point de terminaison, la configuration de déploiement et les informations d'importation.

**État du déploiement**

-   **Déployé** indique que le déploiement du modèle est terminé.


-   **Publié** indique que le modèle déployé a été publié sur la passerelle de modèles d'IA.


Sélectionnez **Afficher les détails** pour consulter les informations sur le modèle de passerelle de modèles d'IA correspondant.

**Détails du point de terminaison**

-   **Point de terminaison :** point de terminaison d'inférence pour le modèle déployé.


-   **Nom du modèle :** nom utilisé pour référencer le modèle via la passerelle de modèles d'IA.


Copiez les valeurs affichées à l'aide des contrôles de copie.

**Détails du déploiement**

Examinez les ressources et la configuration utilisées pour le déploiement.

**Détails du modèle**

Vérifiez le nom du modèle, la source, la famille de modèles et le type de modèle.

**Détails de l'importation**

Examinez la source du modèle, la date d'importation, la version importée et les informations sur l'importateur.

## Mettre le modèle hors service


Mettez le modèle déployé hors service lorsqu'il n'est plus nécessaire pour l'inférence.

**Avant de commencer**

-   Vérifiez que les applications et les utilisateurs n'ont plus besoin du modèle déployé.


-   Vérifiez que la suppression du modèle de la passerelle de modèles d'IA n'interrompra pas une charge de travail active.


-   Consignez toutes les informations relatives aux points de terminaison ou aux déploiements requises pour le suivi opérationnel.


1.  Examinez le nom du modèle et les détails du déploiement.


1.  Sélectionnez **Mettre hors service**.


1.  Vérifiez la confirmation selon laquelle la mise hors service du modèle entraîne l'annulation de son déploiement et sa suppression de la passerelle de modèles d'IA.


1.  Sélectionnez **Mettre hors service** pour confirmer.


Mise hors service du modèle :

-   Annule le déploiement du modèle.


-   Supprime le modèle de la passerelle de modèles d'IA.


-   Conserve le modèle importé dans le registre de modèles.
