Consultez les informations sur le modèle et ouvrez les tâches à votre disposition. Le contenu du tableau de bord dépend de votre rôle et de votre offre Teradata.

## Tableau de bord pour les administrateurs


Consultez les informations relatives aux modèles, à l'accès et au déploiement, et démarrez des tâches administratives courantes. Avec Teradata Factory, le tableau de bord inclut également les informations sur le registre de modèles.

**AI Gateway**

La table **Modèles récemment intégrés** affiche les points de terminaison de modèles récemment ajoutés. Utilisez les informations disponibles sur les modèles pour comparer les modèles par type, fournisseur, version, longueur du contexte et limite de débit.

-   Sélectionnez **Tout afficher** pour ouvrir la liste de modèles dans **Passerelle de modèles d'IA**. Reportez-vous à la section [Explorer les modèles](eoz1778496909062.md).


-   Si vous disposez d'un accès administrateur, sélectionnez **Point de terminaison de modèle** pour ajouter un modèle. Reportez-vous à la section [Ajouter un modèle](fdy1778502087907.md).


**Registre de modèles**

**Remarque :** le registre de modèles n'est disponible qu'avec Teradata Factory et nécessite des privilèges d'administrateur.

Examinez le nombre de modèles enregistrés et déployés dans Registre de modèles.

-   Sélectionnez un modèle récemment enregistré pour examiner son état et ses détails.


-   Si vous disposez d'un accès administrateur, sélectionnez **Importer un modèle** pour importer un modèle pris en charge. Reportez-vous à la section [Importer un modèle](ecc1790524485875.md).


## Tableau de bord pour les utilisateurs de données


Utilisez une clé API virtuelle pour afficher les modèles qui vous sont attribués et parcourir les autres modèles disponibles via la passerelle de modèles d'IA. Si vous ne disposez pas de clé API virtuelle, contactez votre administrateur de plateforme de modèles d'IA.

**Afficher les modèles qui vous ont été attribués**

1.  Saisissez la clé API virtuelle dans le champ **Saisir la clé**.


1.  Sélectionnez **Soumettre**.


Le tableau de bord affiche les modèles attribués à la clé API virtuelle. Les modèles attribués s'affichent également dans l'onglet **Passerelle de modèles d'IA**. Reportez-vous à la section [Explorer les modèles](eoz1778496909062.md).

Pour utiliser une autre clé virtuelle, effacez la clé existante et saisissez la nouvelle clé.

**Comparer la capacité des modèles**

Chaque liste de modèles inclut des informations sur les jetons afin de vous aider à déterminer si le modèle prend en charge vos besoins en matière d'entrées et de réponses.

-   L'option **Jetons d'entrée** indique la quantité de texte que vous pouvez envoyer dans une seule demande. Choisissez un modèle avec une limite d'entrée plus élevée pour des documents ou des historiques de conversations plus longs.


-   L'option **Jetons de sortie** indique la quantité de texte que le modèle peut générer dans une seule réponse. Choisissez un modèle avec une limite de sortie plus élevée si vous avez besoin de réponses plus longues.


Le tableau de bord affiche par défaut les modèles dans une liste. Passez à la vue en cartes à l'aide du contrôle de vue en cartes.
