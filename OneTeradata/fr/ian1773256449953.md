La page du serveur Teradata Enterprise MCP permet un accès rapide aux ressources Enterprise MCP disponibles dans votre environnement AI Studio. Cette page permet d'obtenir des informations de connexion, de générer des jetons d'authentification, de trouver des serveurs MCP et d'accéder aux fonctionnalités de gestion du serveur.

La page fournit les informations et points d'accès suivants. Pour savoir comment utiliser Teradata Enterprise MCP et les outils MCP, reportez-vous au [Guide de l'utilisateur de Teradata Enterprise MCP](https://docs.teradata.com/access?resourceid=enterprise-mcp-book).

## Point de terminaison du serveur


Utilisez le point de terminaison du serveur MCP lors de la configuration des notebooks, des applications d'IA, des agents ou des clients MCP externes.

-   **Serveur MCP par défaut**

    Pour vous connecter au serveur MCP par défaut, utilisez l'URL de serveur affichée dans l'UI.


-   **Serveur MCP déployé par l'administrateur**

    Vous pouvez vous connecter aux serveurs MCP déployés par les administrateurs dans votre environnement AI Studio. Les serveurs déployés par l'administrateur sont indiqués dans la section **Registre**. Sélectionnez un serveur pour ouvrir son interface du serveur MCP intégrée et accéder aux fonctionnalités spécifiques au serveur.

    Si vous avez besoin du point de terminaison du serveur pour la configuration ou l'automatisation du client, récupérez-le à partir des détails du serveur dans l'interface ou en utilisant l'API **Répertorier tous les serveurs**. Pour plus d'informations, reportez-vous à la section [Répertorier tous les serveurs](https://docs.teradata.com/access?resourceid=mcp-srvr-mg-list-servers&utm_source=console&utm_medium=iph).

    Pour accéder à ce point de terminaison, vous devez être connecté au réseau privé sur lequel AI Studio est déployé.


## Générer un jeton


Vous aurez besoin d'un jeton pour authentifier les demandes. Sélectionnez une méthode d'authentification. Pour plus d'informations, reportez-vous à la section [Autorisation, contrôle d'accès basé sur les rôles (RBAC) et authentification](https://docs.teradata.com/access?resourceid=author-rbac-authen).

## Registre


Le registre répertorie les serveurs MCP à votre disposition. La liste peut inclure le serveur MCP par défaut et les serveurs MCP personnalisés déployés par les administrateurs. Sélectionnez un serveur pour ouvrir son interface du serveur MCP intégrée.

L'interface du serveur MCP intégrée permet d'accéder aux connexions, aux groupes d'outils personnalisés, aux outils, aux tâches et aux paramètres d'authentification du serveur sélectionné. Pour plus d'informations sur l'utilisation de l'interface du serveur MCP intégrée, reportez-vous à la section [Interface du serveur MCP](https://docs.teradata.com/access?resourceid=mcp-server-interface).

**Conseil** : si un serveur ne s'affiche pas dans Registre, contactez votre administrateur pour vérifier que le serveur a bien été déployé et mis à disposition sur votre compte.

## Gestion des serveurs


Si vous êtes administrateur, sélectionnez **Serveur MCP** > **Gestion des serveurs** pour déployer, configurer, surveiller, dimensionner, redémarrer et mettre les serveurs MCP hors service. L'option Gestion des serveurs offre des fonctionnalités de gestion du cycle de vie pour les déploiements de serveurs MCP dans votre environnement AI Studio.

Pour les procédures de déploiement et d'administration, reportez-vous à la section [Gestion des serveurs MCP](https://docs.teradata.com/access?resourceid=mcp-server-management).
