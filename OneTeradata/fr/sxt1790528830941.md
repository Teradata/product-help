Transmettez des paramètres d'exécution clé-valeur au serveur de modèles.

**Avant de commencer**

Déterminez si le modèle sélectionné nécessite des arguments personnalisés. Les paramètres d'exécution dépendent du module et de l'environnement d'exécution du modèle.

Pour un modèle Hugging Face prêt à l'emploi, utilisez les arguments documentés pour ce modèle spécifique dans **Paramètres de déploiement du modèle prêt à l'emploi**. Les modules NVIDIA NIM n'incluent pas d'arguments d'exécution personnalisés dans la configuration fournie.

**Ajouter un argument**

1.  Entrez le nom de l'argument dans **Saisir la clé**.


1.  Saisissez le paramètre correspondant dans **Saisir la valeur**.


1.  Sélectionnez **Ajouter un argument** pour ajouter une autre paire clé-valeur.


Pour supprimer un argument, sélectionnez le contrôle de suppression correspondant à cet argument.

Saisissez chaque propriété d'exécution documentée sous forme de paire clé-valeur distincte.

Si le modèle ne nécessite pas d'arguments personnalisés, laissez les champs vides.

**Important :** n'appliquez pas d'arguments d'exécution provenant d'un autre module de modèle. Les paramètres d'exécution varient selon le modèle et l'environnement d'exécution.
