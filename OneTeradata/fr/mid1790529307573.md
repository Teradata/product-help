Examinez la configuration complète avant de déployer le modèle.

Vérifier :

-   Modèle à déployer


-   Nombre de réplicas


-   Pool de nœuds


-   Ressources allouées à chaque réplica


-   Consommation totale estimée des ressources


-   Arguments personnalisés, lorsqu'ils sont fournis


-   Alias de la passerelle de modèles d'IA


Pour modifier un paramètre, sélectionnez **Précédent**, mettez à jour la configuration et revenez à **Résumé**.

Sélectionnez **Déployer** pour démarrer le déploiement.

Une fois le déploiement terminé :

-   L'état du modèle est redéfini sur **Déployé**.


-   L'état de la passerelle de modèles d'IA est redéfini sur **Publié**.


-   La page de détails du modèle affiche le point de terminaison d'inférence et le nom du modèle.


-   Le modèle devient disponible via la passerelle de modèles d'IA.


Vous pouvez ensuite utiliser le modèle via la passerelle de modèles d'IA, le vérifier dans **Terrain de jeu** et examiner son activité dans **Observabilité**.
