La page Intégrations contient les éléments suivants :

-   Versionnez votre code Git avec Gitea : Gitea propose l'hébergement de référentiels, des fonctionnalités d'examen de code et de collaboration en équipe, des registres de modules ainsi qu'une intégration CI/CD. Il permet aux équipes de développement de gérer le code source en toute sécurité, de suivre les modifications et de collaborer tout au long du cycle de vie du développement logiciel.


-   Créez des flux de travail avec Airflow : Airflow fournit une infrastructure basée sur Python pour concevoir des flux de travail qui s'interfacent avec un large éventail de technologies et de services. Son interface Web vous permet de visualiser l'exécution des flux de travail, de suivre la progression, de résoudre les problèmes et de gérer des pipelines de traitement de données complexes.


-   Gérez des modules Python avec devpi : **devpi**, un système de gestion de modules compatible avec PyPI, vous permet de gérer, versionner et distribuer des modules Python dans votre environnement. Avec devpi, vous pouvez gérer des référentiels de modules privés, contrôler les versions des modules et simplifier la gestion des dépendances pour les flux de travail de développement, de test et de déploiement.


-   Exploitez davantage de types de données avec Unstructured : utilisez **Unstructured** pour convertir des contenus non structurés et semi-structurés en données structurées prêtes pour l'IA. Unstructured traite des documents non structurés, tels que les PDF, les présentations, les pages web et autres sources de contenu, en les convertissant en formats exploitables efficacement pour la recherche, la récupération, les analyses et les applications d'IA générative. Cette fonctionnalité contribue à améliorer la qualité, la précision et la pertinence des charges de travail d'IA en aval. Pour plus d'informations, reportez-vous à la section [Intégration d'Unstructured](https://docs.teradata.com/access?resourceid=vectorcollection-unstructured-integration).
